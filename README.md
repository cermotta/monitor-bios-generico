# Monitor de BIOS Genérico (CLI)

Utilitário desenvolvido para identificação automática de hardware e verificação de suporte de BIOS, facilitando o acesso direto aos canais oficiais do fabricante.

## 👨‍💻 Desenvolvedor
**Eduardo Motta**

## 🚀 Funcionalidades
- **Detecção Inteligente:** Identifica automaticamente fabricante e modelo via PowerShell.
- **Segurança:** O software redireciona o usuário para a página de busca oficial da fabricante, garantindo uma navegação segura.
- **Automação:** Contador regressivo de 10 segundos para encerramento automático do sistema.

## 🛠️ Como usar
1. Vá na aba [Releases](https://github.com/cermotta/monitor-bios-generico/releases) e baixe a versão mais recente do `MonitorBIOS_V2.exe`.
2. Execute o programa e siga as instruções exibidas na tela.

## 📝 Notas de Desenvolvimento
Desenvolvido em Python 3.x utilizando bibliotecas nativas do Windows (`subprocess`, `msvcrt`), garantindo leveza e total compatibilidade com o sistema sem dependências externas.
