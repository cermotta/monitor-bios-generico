# Monitor de BIOS Genérico (CLI)

Utilitário desenvolvido para identificação automática de hardware e verificação de suporte de BIOS.

## 👨‍💻 Desenvolvedor
**Eduardo Motta**

## 🚀 Funcionalidades
- **Detecção Inteligente:** Identifica automaticamente fabricante e modelo via PowerShell.
- **Segurança:** Redireciona para a página oficial de busca do fabricante.
- **Automação:** Fechamento automático em 10 segundos.

## 🛠️ Como usar
1. Vá em [Releases](https://github.com/cermotta/monitor-bios-generico/releases) e baixe o `MonitorBIOS_V2.exe`.
2. Execute o programa e siga as instruções na tela.

## 📝 Notas de Desenvolvimento
Desenvolvido em Python 3.x utilizando bibliotecas nativas do Windows (`subprocess`, `msvcrt`).
